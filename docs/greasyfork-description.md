把 huggingface.co 界面上的英文换成中文的用户脚本。只改界面文字，模型卡正文、README、代码块、仓库名保持原样。安装后自动生效，左下角有开关，按 Alt+Z 可以随时切回英文。

## 做什么

Hugging Face 只有英文界面，导航、筛选、排序、卡片角标、分页这些固定词逐个对照很麻烦。脚本内置 729 条词条和一组整段锚定的规则，把这些文字换成中文，另带一组规则处理相对时间、带单位的数量、带计数的标签这类会变的文本。

改动只发生在界面文字所在的文本节点上，页面结构、样式和排版都不动，也不发网络请求。

## 覆盖范围

- 顶部导航，以及悬停展开的任务分类与参数档位
- 搜索框提示（placeholder）、搜索结果页的筛选
- 列表页左侧筛选面板：任务 / 库 / 语言 / 许可证 / 模态 / 参数量 / 大小 / 格式
- 排序下拉的全部选项，和按钮上显示的当前选项（Sort: Trending → 排序：热门）
- 数量与计数：「434,632 models」→「434,632 个模型」，「25k rows」→「25k 行」，「Showing 1-30 of 1,119,876」→「显示 1–30，共 1,119,876 条」，「Page 2 of 13」→「第 2 页，共 13 页」
- 时间：「3 days ago」→「3 天前」，「Sep 1, 2025」→「2025年9月1日」，「Updated 2 hours ago」→「更新于 2 小时前」
- 带计数的标签：「MCP (2)」→「MCP（2）」，「Split (3)」→「划分（3）」，「8 languages」→「8 种语言」
- 模型页：标签页、点赞数与下载量、参数规模（7B params → 7B 参数）、部署按钮、使用此模型下拉、模型树
- 数据集页：数据集查看器、划分与子集标签、列统计、分页
- 空间页：分类导航；卡片角标（运行于 ZeroGPU、智能体、精选、运行中、已暂停）
- 定价页的档位与价格说明、文档侧栏、社区帖子、Learn、博客列表、组织页、登录注册页、页脚
- 浏览器标签页标题：按 · / – / | 切段后逐段匹配
- 按钮与输入框的属性文字：placeholder、title、aria-label、alt、data-tooltip

## 安装

1. 先装 Tampermonkey，Violentmonkey 一类的用户脚本管理器同样可用。
2. 点本页的「安装此脚本」，在脚本管理器弹出的页面里确认安装。
3. 手动安装：打开 https://github.com/u2tt/hf-zh/blob/main/hf-zh.user.js 复制全文，在脚本管理器里新建脚本，粘贴覆盖后保存。

脚本在 document-idle 阶段执行，页面可交互后立即扫描一遍；此后由 MutationObserver 跟随页面重渲染补译，单页应用路由切换时自动重扫。

## 使用

- 打开 huggingface.co 即生效，不需要任何配置。镜像站 hf-mirror.com 同样生效。
- 左下角有直径 30 像素的圆形按钮。显示「中」表示汉化开启，显示「EN」表示已关闭，点一下切换。
- 键盘 Alt+Z 与点按钮等效，用来快速对照原文。
- 选择记在浏览器本地（localStorage 键名 hf-zh:enabled），刷新页面、重开标签页后保持上次的状态。
- 关闭时脚本把自己改过的文本节点还原成原文，不残留半截中文。

## 不翻译的部分

以下区域有意保持英文：

- 代码与等宽字体：code、pre、kbd、samp、textarea、math、svg，以及 font-mono 类元素（仓库名、变量名主要落在这里）。font-mono 里只放行「运行中 / 已暂停 / 精选 / 智能体」几个卡片角标词。
- 卡片正文与 README 渲染区：model-card-content、dataset-card-content、space-card-content、markdown-content、md-content、prose、blog-content 等。
- 专有名词：模型名、数据集名、机构名、仓库名、论文标题、数据集列名。翻过之后没法复制去搜索。
- 图表与 Canvas 内的文字：不是网页文本节点，脚本取不到。
- 登录页的 Cloudflare 人机验证：第三方嵌入组件。

## 权限与隐私

- @grant none：不申请任何 GM_* 接口，没有后台页面，不加载远程代码。
- 除页面自身的 localStorage 外不读写任何存储，不向任何服务器发请求，不上传数据。
- 只在本机浏览器里改文字节点，服务端返回的内容和数据不受影响。

## 兼容性

- 域名：huggingface.co、www.huggingface.co、hf.co、*.hf.co、hf-mirror.com。
- 浏览器：Chrome、Edge、Firefox 实测可用；Safari 需要 Userscripts 一类扩展来运行用户脚本。
- 单页应用路由（pushState / replaceState / popstate）切换后自动重扫，不需要刷新页面。
- 移动端与触屏环境未验证，桌面浏览器为验证环境。

## 已知限制

- 词条是固定词典，站点新增或改写的英文文案要等脚本更新之后才会翻译。
- 单个文本节点归一化后长度小于 2 或超过 90 个字符时跳过，避免把长段落当成界面词替换。
- 只做整段相等匹配，中英文混排的长句（例如文件变更摘要）不逐词替换。
- 登录后的账单、访问令牌等设置页覆盖较少。
- 页面结构大改后可能出现未收录的英文，需要按实际页面补词条。

## 常见问题

- **安装后页面没有变化**：确认脚本管理器已启用、当前域名在支持列表里；用镜像站时确认地址是 hf-mirror.com。
- **某处还是英文**：该段可能不在词典里，或位于上面「不翻译的部分」所列区域。带页面地址和那句英文到仓库提 issue。
- **中文里夹着半截英文单词**：本脚本只做整段相等匹配，不会把单词塞进英文句子里。遇到这种结果先确认是否同时开了别的汉化脚本或浏览器自带翻译。
- **关掉汉化后没恢复**：点按钮或按 Alt+Z 只还原本脚本改过的节点，其他扩展或站点自身改写的文字不归本脚本处理。
- **切换页面后英文重新出现**：多为新版页面结构未被词典覆盖，刷新一次确认，再按页面提 issue。
